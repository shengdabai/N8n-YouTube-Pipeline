# n8n YouTube Pipeline

n8n 自动化工作流 — YouTube 视频采集、分镜拆解与 AI 内容生成。

## 工作流列表

### 1. YouTube对标频道爆款视频采集
自动采集对标频道的热门视频数据，分析爆款特征。

### 2. 视频分镜拆解与AI图片生成
将视频拆解为分镜描述，并调用 AI 生成对应图片。

### 3. 分镜视频生成与自动粗剪
基于分镜图片自动生成视频，并完成初步剪辑。

## 技术栈
- n8n 自动化平台
- AI 视频/图片生成 API

## 使用方法
1. 将 `.json` 工作流文件导入 n8n
2. 配置相应的 API 凭证（环境变量）
3. 激活工作流并触发执行
